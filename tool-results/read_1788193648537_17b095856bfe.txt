     1→# MASTER PROJECT PROMPT — ONLINE ESSAY WRITING COMPETITION MANAGEMENT SYSTEM
     2→
     3→## 1. PROJECT OVERVIEW
     4→
     5→Build a complete, production-ready **Online Essay Writing Competition Management System**.
     6→
     7→The system will be used to organize essay-writing competitions for school students.
     8→
     9→The application must support:
    10→
    11→* Student registration
    12→* Teacher registration
    13→* Teacher-assisted student registration
    14→* Student profile management
    15→* Age-based competition eligibility
    16→* School information
    17→* Registration fee collection
    18→* Razorpay payment integration
    19→* Email verification
    20→* Competition notifications
    21→* Essay PDF upload
    22→* Secure file validation
    23→* Cloudinary file storage
    24→* Examiner management
    25→* Multiple examiners evaluating the same essay
    26→* Examiner marks, comments and justification
    27→* OCR-assisted quotation/reference from essays
    28→* Automatic average/final score calculation
    29→* Administrative financial management
    30→* Complete audit logging
    31→* Admin dashboard
    32→* Competition configuration
    33→* Notification management
    34→* Production deployment on Vercel
    35→* Neon PostgreSQL database
    36→* Resend email service
    37→* Cloudinary file storage
    38→
    39→The system must be designed as a **real production application**, not as a demo, prototype, or toy project.

   403→5. Selects/apply for eligible competition.

   413→
   414→1. Logs into dashboard.
   415→2. Adds student.
   416→3. Student record is created.
   417→4. Student receives invitation/verification email.
   418→5. Student verifies email.
   419→6. Student sets/activates login credentials.
   420→7. Student completes profile.
   421→8. Student pays registration fee.
